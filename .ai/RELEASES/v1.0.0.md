# Release v1.0.0 - Wallet Platform

**Data de Lançamento:** 2026-08-29  
**Versão:** `1.0.0`  
**Status:** Produção / Estável  

---

## 🎯 Visão Geral da Release

A versão **v1.0.0** consolida a primeira entrega estável de ponta a ponta da plataforma financeira **Wallet**, estruturada como um monorepo moderno contendo a aplicação Web em React 19, a API assíncrona FastAPI, o módulo nativo Android com arquitetura Offline-First e a orquestração completa via Docker & Docker Compose.

---

## 📦 Componentes & Versões

| Módulo | Tecnologia | Versão | Descrição |
| :--- | :--- | :---: | :--- |
| **Backend** | Python 3.10 / FastAPI / SQLite WAL | `1.0.0` | API REST assíncrona com SQLAlchemy 2.0 e Pydantic v2. |
| **Frontend** | React 19 / TypeScript / Vite / Tailwind | `1.0.0` | Painel web responsivo com suporte a Dark Mode. |
| **Android** | Kotlin 2.0 / Compose / Room | `1.0.0-scaffold` | Aplicativo nativo offline-first com Room e WorkManager. |
| **Docker** | Nginx Alpine + Python Slim | `1.0.0` | Imagens otimizadas com proxy reverso e healthchecks. |

---

## 🚀 Novas Funcionalidades e Entregas

1. **Containerização Completa**:
   - `docker-compose.yml` para execução em produção com 1 comando.
   - Nginx Alpine servindo a SPA React com Gzip, cache de assets e proxy reverso `/api/` para o FastAPI.
   - Volume nomeado `wallet_data` para persistência segura do banco SQLite e comprovantes.
2. **Módulo de Cartões de Crédito & Ciclo de Faturas**:
   - Isolamento das compras por fatura com deduplicação de métricas no dashboard.
   - Tela `CreditCards.tsx` com cartões virtuais dinâmicos, acompanhamento de limites e liquidação atômica.
3. **Módulo Nativo Android (Offline-First)**:
   - Scaffold completo compatível com o Android Studio.
   - Entidades Room com valores estritamente em centavos (`amountCents: Long`).
   - Sincronização delta em segundo plano via WorkManager.
4. **Governança & SSOT**:
   - Versionamento semântico centralizado (`VERSION` e `CHANGELOG.md`).
   - 17 Decisões Arquiteturais documentadas em `.ai/DECISIONS/`.

## 🛠️ Como Subir a Release com Docker

```bash
# 1. Clonar o repositório ou atualizar
git pull origin main

# 2. Construir e iniciar os containers em segundo plano
docker compose up -d --build

# 3. Acessar a aplicação
# Web App: http://localhost:5173 (ou IP da sua rede)
# Backend Swagger: http://localhost:8000/docs
```
