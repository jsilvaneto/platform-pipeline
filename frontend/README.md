# Wallet Frontend

Interface Web desenvolvida com **React 19**, **TypeScript**, **Vite** e **Tailwind CSS**.

## Scripts Disponíveis

- `npm run dev`: Inicia o servidor de desenvolvimento Vite em `http://localhost:5173`.
- `npm run build`: Executa a verificação de tipos com o TypeScript (`tsc -b`) e gera o bundle de produção via Vite em `dist/`.
- `npm run preview`: Visualiza o bundle de produção localmente.

## Principais Recursos
- Alternador de perfil **Pessoal** vs **Empresa**
- Modo Escuro / Modo Claro (*Dark/Light Mode*)
- Botão para ocultar valores na tela
- Central de conexão da API REST e guia interativo do app Android (Offline-First)
- Gestão completa de lançamentos, parcelamentos e agendamentos
- Painel de controle com KPIs e projeções de fluxo de caixa
- Cadastros de categorias, itens com valores sugeridos, contas, formas de pagamento, cartões de crédito, contatos, dívidas e metas orçamentárias
